# Can Kyoto
Web del restaurant Can Kyoto Projecte Modul 0379.


## Pàgines

- `index.html`: portada, i pagina principal (home)
- `reserves.html`: pagina oberta i especifica per a reserves
- `carta.html`: carta per als clients

## Carpetes

- `css/style.css`: full d'estils (tota la web)
- `js/taules.js`: 10 taules js
- `js/sala.js`: pinta el plànol de la portada amb les taules lliures i ocupades.
- `js/reserves.js`: el procés de reserva.
- `js/carta.js`: cer canviar l'idioma   
- `img/`: imatges
- `php/`: backend(mini)
